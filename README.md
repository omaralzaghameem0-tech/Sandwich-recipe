# Peanut butter sandwich

A **five-minute** lunch for one person.

## What you need


- 2 slices of bread
- Peanut butter
- Jam
  - Strawberry, if you have it

## Steps

1. Spread peanut butter on one slice.
2. Spread jam on the other.
3. Put them together and cut.
